# Bike Buyers Analysis Dashboard (Excel)

An Excel project analysing which customers buy bikes, using a sample dataset of 1,000 customers.

## What I did
- Cleaned the data (removed 26 duplicate rows)
- Created Age Group and Income Group columns using IF formulas
- Built summary tables with COUNTIF, COUNTIFS and AVERAGE
- Made PivotTables to double-check the results
- Designed a dashboard with KPI boxes and charts

## Key findings
- Overall purchase rate: 48.1% (481 out of 1,000 customers)
- Middle-aged customers buy the most (54.6%), and older customers the least (31.2%)
- Pacific region has the highest purchase rate (58.8%)
- Purchase rate rises with income, from 40% (Low) to 53% (High)

## Tools
Microsoft Excel (Tables, formulas, PivotTables, charts)
